# C Programming Intro: Project 2 Formative Assignment

This repo has my three C projects for the assignment. Each project is in its own folder with its source code, a README and screenshots. Open the README inside a folder to see how it works and how to run it.

## What is in each folder

- **`Project 1/`**: Dynamic Academic Performance and Risk Analysis Engine. A menu program to manage student records (add, remove, sort, search, averages, summary) with a dynamic array.
- **`Project 2/`**: Dynamic Text Mining and Linguistic Pattern Analyzer. It reads a paragraph, counts the words, and shows word statistics, search, sorting and a custom lexical diversity score.
- **`Project 3/`**: Dynamic IoT Event Monitoring and Callback Engine. It registers devices, makes random readings, checks them with callback functions, and shows alerts and a summary.

## Folder layout

Each project folder has about the same things:

- `.c` and `.h` files with the source code
- `README.md` that explains the solution
- `screenshots/` with pictures of the program running
- the compiled `.exe` for Windows
